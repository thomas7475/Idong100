Turn-20 changes (fix for the turn-19 kit):
- The turn-19 patched installers failed the NSIS stub's integrity check
  ('NSIS Error - Installer integrity check has failed') because the repack
  left a stale CRC + length_of_all_following_data. The check (recovered by
  Unicorn-emulating the stub's loadHeaders): crc32(file[512 .. fh+x2-4))
  must equal the u32 stored at fh+x2-4. The turn-20 rebuild recomputes x2 and
  appends a fresh CRC; both patched installers now PASS the actual stub code
  in emulation (scripts/rebuild_patched_installers20.py +
  scripts/emulate_stub_check20.py).

Turn-19 changes (on top of turn 16/17/18):
- OS-version gate SOLVED: the installers' VersionCheck.dll whitelists
  only XP 5.1 / Vista 6.0 / Win7 6.1 (WOW64: Win7 only) and exits with
  the OS-incompatibility dialog on Win8/10/11. Compatibility mode
  cannot fix it (the gate reads _winmajor/_winminor from MSVCR80.dll,
  not GetVersionEx). New patched installers: xeyez_setup_patched.exe
  and xeyez_alone_patched.dat - 4 gate jumps rewritten, every path
  returns 0; solid NSIS stream decompressed/repatched/recompressed,
  round-trip verified; stale Authenticode dir zeroed.
- install_patched.bat (new): backs up originals, swaps in the patched
  installers, launches. Pure cmd.
- check_gate.bat rewritten: fixed the ')' parse crash (German cmd
  error - probe labels contained parentheses inside if-blocks), fixed
  truncated value display, now also reports the patched-installer
  presence. Ends with pause (stays open).
- check_capture.bat / run_capture.bat: pause added at every exit; a
  parenthesised echo inside an if-block fixed.

Turn-18 changes (on top of turn 16/17):
- platform_mark.reg v2: writes BOTH registry views (64-bit +
  Wow6432Node). Root cause of the turn-17 retry: the gate DLL is
  32-bit, so on 64-bit Windows it reads the Wow6432Node view, which
  v1 never wrote. Compatibility mode cannot change that.
- check_gate.ps1 -> check_gate.bat: pure cmd (no PowerShell, user
  rule). Reports BOTH views, creates %ProgramData%\i-dong, checks
  the xeyez service.
- check_capture.ps1 -> check_capture.bat: pure cmd + embedded
  cscript scanner (byte-accurate, same exit codes 0/2).
- run_capture.bat now calls check_capture.bat (no PowerShell).
- The turn-17 .ps1 scripts are retired from the kit.
