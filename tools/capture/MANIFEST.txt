Inside the Windows 7 (VM or PC) that has the sensor, in this order:
  1. software\USBPcapSetup-1.5.4.0.exe   install, then RESTART Windows
  2. test_usbpcap.bat                    is USBPcap installed and recording?
  3. run_capture.bat                     record one complete sensor boot
  4. check_capture.bat                   read the capture, print the verdict
Read README_CAPTURE.md first. Captures go to C:\idong_capture\runN, or to
the fallback folder the scripts name when it is write-protected.
All scripts are pure cmd.exe and keep their window open.
