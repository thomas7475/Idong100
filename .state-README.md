# project/state — branch index

This branch holds the **current project state** after every session.
It is updated at the end of each turn (working rule, 2026-11-24).

## What lives here

driver code), `research/` (the work it grew out of), `tools/` (the
Windows bench kits) and `deliverables/` (the PDF reports).

## Conventions

- One commit per session-turn: message format
  `state(turn N): <summary>` (N = conversation turn number).
- The driver is `software/` only. The turn-13 scaffold under
  `deliverables/` and the turn-10 crate under `research/idong100/rust/`
  are frozen historical snapshots, not maintained code.
- Chat context backups do **not** live here — they are on the
  `chat/context` branch.
- The vendor device files are committed under `software/firmware/`
  (turn 40): byte-exact, listed in `SHA256SUMS`, pinned by the
  `firmware_files` test; `.gitattributes` keeps git from rewriting their
  line endings. The vendor's terms ship with them (`licence.txt`).
